# 远程功能说明

PyManager 的远程能力基于 SSH 和 SFTP，面向专用服务器或测试环境。当前远程功能主要包括连接管理、环境扫描、包管理和文件浏览。

## 连接管理

- 支持保存远程服务器配置。
- 支持账号密码或密钥方式连接。
- 启动后会后台尝试连接第一个已保存服务器。
- 自动连接使用短超时，避免远程不可用时拖慢程序启动。

## 远程环境管理

- 扫描远程 conda 环境和 venv 环境。
- 创建、删除远程 venv 或 conda 环境。
- 安装、卸载、更新 Python 包。
- 导入/导出 requirements。
- 导入/导出 conda YAML。

## 远程文件浏览

- 通过 SFTP 浏览目录。
- 支持返回上级目录、刷新、新建目录、重命名、删除和查看文本文件。
- 显示文件类型、大小、权限和修改时间。
- 支持 `~` 路径展开，并对远程路径做 shell 引用处理。

## 当前限制

- 远程真实验收需要目标 SSH 服务处于可连接状态。
- 对需要 root 权限的远程系统级安装，仍依赖服务器 sudo 策略。
- Windows 本机的 WSL 和远程 Linux 命令语义不同，新增能力应分别验证。
